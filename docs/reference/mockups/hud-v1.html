What this is

A throwaway information-design artefact for Odyssey, a colony sim in true 3D with discrete vertical layers. It exists so the interface can be judged before it is built. It is not a prototype and shares no code with the game.

Specified in docs/design/09-ui-and-input.md and docs/design/10-ui-panel-catalogue.md. Every region here carries its catalogue identifier; turn on Annotate regions to see the director, the view fields and the update cadence for each.

The question to answer first

The concept renders are all single-layer cut-aways, so they never showed what sits above the layer you are working on. That is the one genuinely open design decision.

Move the slice on the Depth Ruler, then cycle Above through its three positions:

  • Hide — maximum clarity, no sense of what is overhead.
  • Ghost — structural outlines only. The provisional recommendation.
  • X-ray — everything translucent. Most information, busiest picture.

Two comparable games take opposite positions here, so this is a taste call, not a research finding.

Icons before any art exists

No icon in the game has been drawn. Every one is referenced by a symbolic key such as ui.res.alloy, and a generator makes a deterministic placeholder from the key — stable hue, stable abbreviation — so layout and density can be reviewed now and real art drops in later with no code change.

The Icons control cycles the four debug modes the game will ship: keys drawn over icons for self-documenting screenshots, a text-only accessibility fallback, and the magenta missing-icon mode that keeps the art backlog visible.

Deliberately different from the concept

  • The duplicated colonist row at the bottom of the concept is gone. The top roster bar survives and each card gained a layer badge.
  • The freed right edge carries the Depth Ruler: occupancy per layer, colonist counts, and a marker where an alert is pending.
  • Every alert and bulletin carries the layer it happened on and jumps the slice when clicked. Try the red one.
  • Time, date, weather and speed controls were missing from the concept entirely. Added top-right.

Where the performance work is

The overlays are the trap. One layer of the agreed footprint is 62,500 cells, so an interface element per cell is wrong by three orders of magnitude. Overlays are drawn as one texture per layer sampled through a colour ramp, on a single quad.

Only the legend is interface. Toggle an overlay and watch the world tint, not the DOM grow.

The dense grid in the Work panel is the other one, and it is the experiment that decides whether the chosen framework survives.

Known to be unfinished

  • The world is a placeholder renderer, not the game. No Synty content appears here and none ever will — licensed assets stay out of the repository.
  • The Work panel shows 12 colonists by 14 work types. The real one is 50 by 25 and is virtualised.
  • Panel positions are fixed. The real ones are draggable and remember where you left them.
  • Wide screens only, really. The real interface targets 1080p with a scale slider.
