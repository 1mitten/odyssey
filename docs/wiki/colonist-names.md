# Colonist names

The pool every colonist's given name is drawn from. A name is chosen by arithmetic on a colonist's saved seed and their slot, so the **order of this list is load-bearing**: reordering it renames every colonist in every existing save. Add to the end; never sort.

240 names — settled 97, frontier 106, yard 37.

---

**Gender is recorded and nothing reads it.** No pawn in the simulation has a gender, and the drawn colonist is one of sixty-one Synty models in a single undifferentiated family — so a gendered name could not yet be made to agree with the figure beside it. The column is here because it cannot be re-derived cheaply later, and because the wiki is where the owner corrects it.
