Every named thing in the game

This page is the naming reference for the prototype: every commodity, building, command, work type, body part and alert the interface can refer to, with the stable key beside it. It exists to be corrected. If a name is wrong, cite its key.

It is generated from the design data, so it cannot drift from the game. Names and descriptions come from docs/design/icon-keys.csv; whether the owner's pixel-art sheets can draw a thing comes from docs/design/icon-map.csv; people, places and factions come from docs/design/proper-nouns.csv.
