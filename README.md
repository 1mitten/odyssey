# Odyssey

A prototype colony sim in the RimWorld mould, in true 3D with discrete vertical layers, set in a ruined sci-fi city. Unity 6.3 LTS, URP, C#. Art from Synty POLYGON Sci-Fi City (licensed; never committed to this repository).

- Start here: `CLAUDE.md` (project guide) and `docs/brief.md` (the governing brief).
- Research: `docs/research/INDEX.md`.
- Dev-machine setup: `docs/setup/local-dev.md`.
- Headless Unity: `scripts/unity.sh`.

Status: Phase 0 (ground) done; Phase 1 (interview) awaiting answers; the Synty inventory and import spike must be run on the dev machine.
